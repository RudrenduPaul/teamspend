# teamspend

Compare what your team spent on one AI coding tool before a migration against what you spend on another one after it.

    npx teamspend snapshot --tools cursor,claude-code --before 2026-04-01:2026-04-30 --after 2026-06-01:2026-06-30

This README is a placeholder -- the full version with benchmarks against comparable tools ships in a later pass of this build pipeline (see `strategy-oss-all-implementation-plan/teamspend/teamspend-execution-plan-2026-07-11.md` in the planning repo).
